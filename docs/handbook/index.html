              Kryonux справочник

              Установка Kryonux v0.0.1 на x86_64.

              1. О Kryonux

              Kryonux это быстрый и усиленный linux для x86_64: openrc, ядро kryonk на основе kernel.org, limine, пакеты из исходников через kpkg. Ставится с live iso одной командой, после установки в системе только консоль.

              ПараметрЗначение
              Архитектураx86_64
              libcglibc
              InitOpenRC
              Ядроkryonk на основе kernel.org, драйверы дисков и файловых систем встроены; initramfs нужен только для luks2
              ЗагрузчикLimine
              Файловые системыext4 и btrfs (zstd)
              ПакетыТолько из исходников, команда kpkg

              1.1 Что нужно

              ЧтоОриентир
              ПроцессорЛюбой x86_64, один образ для всех
              ОзуОт 2 гб
              ДискОт 10 гб, под сборку пакетов лучше 20 гб
              ЗагрузкаUEFI или bios (в bios диск до 2 тб)
              СетьПроводная по dhcp или wifi через iwctl
              НосительФлешка или диск с live iso

              1.2 Что внутри

              GCC, glibc, binutils, python, openrc, udev, dhcpcd, iwd для wifi, opendoas вместо sudo, curl, git, nano, wget, rsync, openssh (выключен), nftables, gnupg, man-db, dosfstools, kpkg. Графики и окружений нет.

              1.3 Что настроено на скорость и защиту

              ОбластьЧто сделано
              Скорость загрузкиБез шифрования ядро грузится без initramfs: диски и ext4/btrfs встроены, openrc запускает службы параллельно, ядро сжато zstd
              Скорость работыnoatime, btrfs со сжатием zstd, tcp bbr, планировщики дисков bfq, kyber и deadline, schedutil, zswap и zram с zstd, thp только по запросу
              ЯдроKSPP-набор опций: рандомизация, hardened usercopy, инициализация памяти, обязательная подпись модулей, yama ptrace_scope 2, lockdown-подобные ограничения, отключены kexec, devkmem, vsyscall
              Сетьnftables с политикой drop включён сразу, ssh выключен, sysctl с защитой от spoofing, redirect и source routing
              ДоступАдминистративные команды через doas и группу wheel, root-пароль задаётся при установке, паролей по умолчанию нет
              Заметка образ по умолчанию собран без -march=native, поэтому работает на любом x86_64. При необходимости iso можно собрать под x86-64-v3, для этого нужен процессор с avx2.

              1.4 Чего пока нет

              Графики нет. Скрипты secure boot на своих ключах, подписанного uki и luks2 с tpm2 есть (см. 5.6), но на реальном железе они пока не проверялись. AppArmor включён в ядре, готовых профилей нет. Профиль проверки cis есть, selinux нет. Честно: полностью неуязвимых систем не бывает, Kryonux даёт усиленную базовую конфигурацию, а не гарантию.

              2. Подготовка

              2.1 Запись iso на флешку

              Скачай iso и контрольную сумму со страницы релизов и проверь:

              sha256sum -c kryonux-live-amd64-0.0.1.iso.sha256

              Запиши образ на флешку (внимание: выбери именно флешку, её данные сотрутся):

              sudo dd if=kryonux-live-amd64-0.0.1.iso of=/dev/sdX bs=4M status=progress conv=fsync

              2.2 Вход в live

              Загрузись с флешки. Вход автоматический: пользователь kryonux, пароль kryonux, root-права через doas -s. Это только для live, ssh для этих учётных записей закрыт, фаервол включён.

              2.3 Сеть

              Для установки сеть не нужна. Проводная сеть поднимается сама. Wifi:

              doas iwctl station wlan0 scan
doas iwctl station wlan0 get-networks
doas iwctl station wlan0 connect имя_сети
              ip addr
ping -c1 github.com

              3. Установка одной командой

              В live выполни:

              doas kryonux-install

              Установщик спросит диск, файловую систему (ext4 или btrfs), имя компьютера, имя пользователя и два пароля. Дальше он сам делает всё:

              1. Размечает диск: gpt и efi раздел 512 мб для uefi, dos и загрузочный раздел 512 мб для bios, остальное под корень
              2. Форматирует разделы и монтирует их в /mnt/kryonux
              3. Распаковывает систему из iso через unsquashfs
              4. Пишет fstab, ставит limine и ядро в /boot
              5. Убирает следы live, создаёт пользователя и пароли
              6. Проверяет результат и размонтирует диск

              Сначала установщик спрашивает режим. Auto стирает весь выбранный диск. Manual даёт разметить диск самому через cfdisk, fdisk или sfdisk, потом спрашивает раздел для boot (efi раздел при uefi, vfat, от 100 мб) и раздел для root (от 4 гб). Трогаются только эти два раздела, остальные разделы и данные остаются. Существующий vfat раздел boot можно оставить как есть, старый загрузчик сохраняется как BOOTX64.EFI.bak. Для скриптов: KRYONUX_MODE=manual KRYONUX_ROOT=/dev/sda3 KRYONUX_BOOT=/dev/sda1 KRYONUX_FORMAT_BOOT=0.

              Важно в режиме auto выбранный диск стирается целиком, в manual только раздел root (и boot, если форматируешь его). Установщик не даёт выбрать носитель, с которого загружен iso, и просит ввести путь диска для подтверждения.

              Когда увидишь «готово», выполни reboot и вытащи флешку. Без вопросов (для скриптов) установщик запускается переменными, список по kryonux-install --help.

              4. Установка вручную

              То же самое, что делает kryonux-install, по шагам. Нужно, если хочешь свою разметку, другую точку монтирования или просто понять, как это устроено. Команды выполняй от root (doas -s). Ниже /dev/sda это пример, смотри свой диск в lsblk.

              4.1 Разметка

              sfdisk /dev/sda <<EOF
label: gpt
,512M,U
,,L
EOF
              sfdisk /dev/sda <<EOF
label: dos
,512M,c,*
,,L
EOF
              Важно все данные на выбранном диске сотрутся. Для nvme разделы называются nvme0n1p1 и nvme0n1p2.

              4.2 Файловые системы и монтирование

              mkfs.vfat -F32 /dev/sda1
mkfs.ext4 /dev/sda2
mkdir -p /mnt/kryonux
mount -o noatime /dev/sda2 /mnt/kryonux

              Вместо ext4 можно btrfs со сжатием:

              mkfs.btrfs /dev/sda2
mount -o noatime,compress=zstd:1 /dev/sda2 /mnt/kryonux

              4.3 Распаковка системы

              unsquashfs -f -d /mnt/kryonux /media/cdrom/kryonux/rootfs.squashfs
mkdir -p /mnt/kryonux/{proc,sys,dev,run,tmp,var/tmp,mnt,media}
chmod 1777 /mnt/kryonux/tmp /mnt/kryonux/var/tmp
mount -o umask=0077 /dev/sda1 /mnt/kryonux/boot
cp /media/cdrom/boot/vmlinuz /mnt/kryonux/boot/vmlinuz

              Если iso записан на флешку и смонтирован не в /media/cdrom, смотри findmnt.

              4.4 fstab

              blkid /dev/sda1 /dev/sda2

              Возьми значения UUID и PARTUUID из вывода. Файл /mnt/kryonux/etc/fstab:

              UUID=UUID_КОРНЯ / ext4 noatime,errors=remount-ro 0 1
UUID=UUID_BOOT /boot vfat umask=0077,noatime 0 2
tmpfs /tmp tmpfs nosuid,nodev,mode=1777 0 0

              4.5 Загрузчик limine

              mkdir -p /mnt/kryonux/boot/limine
nano /mnt/kryonux/boot/limine/limine.conf

              Содержимое (PARTUUID корневого раздела из blkid, тип файловой системы свой):

              timeout: 3

/Kryonux
    protocol: linux
    path: boot():/vmlinuz
    cmdline: root=PARTUUID=PARTUUID_КОРНЯ rootfstype=ext4 rw quiet slab_nomerge init_on_alloc=1 page_alloc.shuffle=1 randomize_kstack_offset=on vsyscall=none debugfs=off pti=on module.sig_enforce=1
              mkdir -p /mnt/kryonux/boot/EFI/BOOT
cp /usr/share/limine/BOOTX64.EFI /usr/share/limine/BOOTIA32.EFI /mnt/kryonux/boot/EFI/BOOT/
              cp /usr/share/limine/limine-bios.sys /mnt/kryonux/boot/limine/
limine bios-install /dev/sda

              4.6 Настройка внутри

              mount --rbind /dev /mnt/kryonux/dev
mount -t proc proc /mnt/kryonux/proc
mount --rbind /sys /mnt/kryonux/sys
mount -t tmpfs tmpfs /mnt/kryonux/run
chroot /mnt/kryonux /bin/bash

              Внутри chroot убери следы live, создай пользователя и пароли:

              rm -f /etc/init.d/kryonux-smoke /etc/runlevels/default/kryonux-smoke /etc/conf.d/agetty.tty1 /etc/ssh/sshd_config.d/05-kryonux-live.conf
userdel -r kryonux
useradd -m -G wheel,users,video,audio,netdev -s /bin/bash имя
passwd имя
passwd
echo "permit persist :wheel" > /etc/doas.conf
chmod 600 /etc/doas.conf
echo 'hostname="kryonux"' > /etc/conf.d/hostname

              4.7 Завершение

              exit
umount -R /mnt/kryonux
reboot

              5. После установки

              5.1 Вход и права

              Входи под созданным пользователем. Команды от root выполняются через doas:

              doas kpkg install nano

              5.2 Часовой пояс и имя

              ls /usr/share/zoneinfo
doas ln -sfv /usr/share/zoneinfo/Europe/Moscow /etc/localtime
date

              5.3 Сеть

              dhcpcd получает адрес сам. Для wifi:

              doas iwctl station wlan0 connect имя_сети
ip addr

              Постоянный адрес задаётся в /etc/dhcpcd.conf.

              5.4 Службы и фаервол

              rc-update show
doas rc-service sshd start
doas rc-update add sshd default
doas kryonux-firewall status
doas kryonux-audit

              SSH по умолчанию выключен, фаервол nftables включён с политикой drop. Перед включением sshd открой порт командами kryonux-firewall (см. kryonux-firewall без аргументов).

              5.5 Swap и zram

              Swap не обязателен. Файлом:

              doas dd if=/dev/zero of=/swapfile bs=1M count=4096 status=progress
doas chmod 600 /swapfile
doas mkswap /swapfile
doas swapon /swapfile

              И строка в /etc/fstab: /swapfile none swap defaults 0 0. Ядро поддерживает zswap и zram со сжатием zstd.

              5.6 Защита: apparmor, uki, tpm2, cis

              Скрипты secure boot, uki и tpm2 ниже есть в репозитории, но на реальном железе они пока не проверялись.

              AppArmor включён в ядре. Пользовательских утилит и готовых профилей в системе нет. Профили и userspace ставятся отдельно; после этого профиль включается через aa-enforce, состояние смотрится через aa-status.

              Подписанный uki: ядро, initramfs и параметры ядра в одном файле, подписанном твоим ключом db. Включается при установке (KRYONUX_SECUREBOOT=1 KRYONUX_UKI=1) или потом: doas kryonux-uki build && doas kryonux-secureboot sign. Параметры зашиты в образ и при загрузке не меняются. После каждого обновления ядра команды нужно повторить.

              TPM2 для luks: doas kryonux-tpm2 enroll запечатывает ключ диска в tpm2 по pcr 7 (состояние secure boot) и добавляет слот 7. Запускай, когда secure boot уже включён и система с ним загружена. При смене ключей, выключении secure boot или переносе диска tpm ключ не отдаст, и система спросит пароль luks. Пароль остаётся рабочим всегда, сохрани его. Убрать: doas kryonux-tpm2 remove.

              Профиль cis: doas kryonux-audit --cis добавляет к проверке права на файлы, пароли, отключённые лишние файловые системы, сетевые параметры и ssh. Это проверки по мотивам cis benchmark, а не сертификация.

              6. Пакеты и kpkg

              kpkg ставит пакеты из исходников по своим рецептам.

              doas kpkg sync
kpkg search имя
kpkg info имя
doas kpkg install имя
doas kpkg remove имя
doas kpkg upgrade
doas kpkg clean

              Если пакет не собрался, смотри последние строки лога и поищи ошибку в разделе ошибки и решения. Для сборки нужно место в /var/tmp и достаточно озу.

              7. Своё ядро (по желанию)

              Ядро из iso подходит для большинства машин, его настраивать не нужно. Свою сборку делают, если нужен драйвер, которого нет в образе. В системе уже есть gcc, make и всё нужное.

              cd /usr/src
curl -LO https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.18.10.tar.xz
tar xf linux-6.18.10.tar.xz
cd linux-6.18.10
zcat /proc/config.gz > .config 2>/dev/null || make defconfig
make menuconfig
make -j$(nproc)
doas make modules_install
doas cp arch/x86/boot/bzImage /boot/vmlinuz-6.18.10

              Добавь второй пункт в /boot/limine/limine.conf с path: boot():/vmlinuz-6.18.10 и перезагрузись. Диск и корневая файловая система должны быть встроены в ядро (=y): при установке без шифрования initramfs нет. В cmdline стоит module.sig_enforce=1: модули своего ядра нужно подписывать или убрать этот параметр.

              8. Обслуживание

              doas kpkg sync
doas kpkg upgrade
doas kpkg clean
df -h

              Обновления самой системы выходят новыми версиями live iso: ставь заново или обновляй пакеты через kpkg. Резервная копия:

              doas tar cpf /mnt/usb/kryonux-backup.tar.xz --xattrs-include='*.*' --numeric-owner --one-file-system -I xz /

              9. Ошибки и решения

              ПроблемаЧто делать
              Установщик пишет «нет mkfs.btrfs»В этом iso нет btrfs-progs, выбери ext4
              Установщик не видит дискПроверь lsblk. Диск с iso исключён намеренно
              После установки не грузится uefiВыбери диск в меню загрузки прошивки. Файл должен лежать в /boot/EFI/BOOT/BOOTX64.EFI
              Kernel panic: unable to mount rootСверь root=PARTUUID= в limine.conf с blkid. Контроллеры вне sata, nvme, virtio и usb-накопителей могут требовать своего ядра, см. 7
              Нет сети по wifidoas iwctl station wlan0 scan, затем connect. Прошивки уже в системе
              Забыл парольЗагрузись с live iso, смонтируй корень в /mnt/kryonux, chroot, passwd
              Пакет не собралсяdoas kpkg sync и повтор. При ошибке сообщи на форуме с последними строками лога

              11. Вопросы и ответы

              Можно ли ставить на сервер

              Можно, но помни про честные пределы: обновления выходят вручную. kpkg update проверяет подпись, но готовых профилей apparmor и userspace-утилит нет: свои профили нужно добавлять и включать самому. Для критичных систем сам оцени риски.

              Где скачать образ

              Live iso и контрольные суммы выходят в релизах на странице релизов, актуальная версия проекта 0.0.1. Установщик уже входит в образ, отдельные архивы не нужны.

              Есть ли secure boot

              Скрипты есть: KRYONUX_SECUREBOOT=1 в установщике и команда kryonux-secureboot (свои ключи, подпись limine, хеши ядра). Подписанный unified kernel image добавляется через KRYONUX_UKI=1. На реальном железе эта цепочка пока не проверялась.
