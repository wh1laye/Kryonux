# 🌐 Kryonux website

Static site published at https://wh1laye.github.io/Kryonux/ and https://kryonux.pages.dev/.

## 🗺️ Pages

| Path | Page |
| :--- | :--- |
| `/` | Home |
| `handbook/`, `handbook/en/` | Handbook (Russian and English) |
| `releases/` | Releases |
| `news/` | News |
| `compare/` | Comparison with other distributions |
| `hardware/` | Hardware compatibility |
| `status/` | Build status |
| `security/` | Security model |
| `forum/` | Forum |

## 🌍 Languages

Pages are written in Russian. English is provided by `i18n.js` dictionaries, and the handbook has a separate English page in `handbook/en/`.

## 🎨 Assets

`logo.svg`, `logo.png`, `icon.svg`, `favicon.ico`, `apple-touch-icon.png`, `og.png` and the icons in `icons/`.
