Из чего состоит


Каждый компонент выбран за простоту и предсказуемость, а не за количество галочек.


Быстрая установка
Система распаковывается прямо из iso, без скачивания и компиляции. Режим auto сам размечает выбранный диск, режим manual трогает только разделы root и boot.
kryonux-installext4btrfsluks2uefibios
Усиленная база
KSPP-опции ядра, подпись модулей, nftables с drop, обычный пользователь в wheel с doas.
KSPPnftablesdoas
Ядро kryonk
Драйверы дисков и файловых систем встроены: без шифрования система загружается без initramfs.
OpenRC
Простая система служб без systemd, службы стартуют параллельно.
Limine
Быстрый загрузчик с одним файлом конфига, для uefi и bios.
kpkg
Пакеты из исходников, свои рецепты, снимки btrfs перед обновлением.
Secure boot и tpm2
Свои ключи secure boot, подписанный uki, разблокировка luks через tpm2 с запасным паролем. На реальном железе скрипты пока не проверены.
kryonux-securebootkryonux-ukikryonux-tpm2

Безопасность по умолчанию


Защита включена сразу после установки, а не спрятана в главе «потом настроишь».


Фаервол с первой загрузки
nftables: входящие закрыты, исходящие открыты. Управление через kryonux-firewall.
Подписанные релизы
SHA-256 всех файлов и подпись minisign для iso, публичный ключ лежит на сайте.
Attestation в github actions
Происхождение сборки подтверждается в самом github, а не только словами.
sshd выключен
OpenSSH стоит, но не запущен. Root по ssh закрыт, включается двумя командами.






kpkg


Свой пакетный менеджер: пакеты собираются из исходников, на btrfs перед обновлением делается снимок.




kpkg
$doas kpkg sync$doas kpkg search htop$doas kpkg install -a htop$doas kpkg upgrade$doas kpkg rollback


Снимки btrfs
Upgrade сначала делает снимок корня, rollback загружается из него.
Проверка при установке
Исходники kpkg проверяются подписью minisign, без неё установка отменяется.
Доктор
kpkg doctor проверяет настройку, kpkg fix чинит окружение сборки.

Частые вопросы


Это отдельный дистрибутив или сборка чужого?
Собственная система: база собрана по lfs с glibc, свой установщик, свой загрузочный образ и свои сборочные скрипты. Рецепты пакетов в kpkg написаны для проекта.
На каком железе работает?
Только x86_64, uefi и старый bios. На странице «железо» собрано, на чём проверено.
Есть ли графика?
Нет, после установки только консоль. Всё остальное ты добавляешь сам через kpkg.
Как проверить, что iso не подменён?
Сверь sha256 и, если в релизе есть файл .minisig, подпись minisign ключом с сайта. Файлы и суммы лежат на странице релизов.
Безопасно ли в live пароль Kryonux?
Пароль Kryonux известен всем и нужен только для live, ssh в live закрыт. В установленной системе такого пароля нет.
