# Kryonux Support

## Getting Help

If you need help with Kryonux, use one of the following resources:

- **Website:** https://wh1laye.github.io/Kryonux/
- **Handbook:** https://wh1laye.github.io/Kryonux/handbook/en/
- **Community Forum:** https://wh1laye.github.io/Kryonux/forum/
- **GitHub Issues:** https://github.com/wh1laye/Kryonux/issues

## Reporting Bugs

If you encounter a bug, please open a GitHub Issue.

Include:
- Kryonux version.
- Hardware and architecture.
- Steps to reproduce the problem.
- Relevant error messages or logs.

## Security Issues

Please do not report security vulnerabilities publicly.

Follow the instructions in [SECURITY.md](SECURITY.md).

## Community Guidelines

Please be respectful when asking questions and helping other users.

Read our [Code of Conduct](CODE_OF_CONDUCT.md) before participating.

## Before Asking for Help

Please check the handbook and existing issues first. This helps avoid duplicate reports and makes it easier to find solutions.
