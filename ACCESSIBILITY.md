# Accessibility Statement

## Our Commitment

The Kryonux project aims to make its software, documentation, website, and community resources accessible and usable by as many people as possible.

We believe that everyone should be able to explore, use, and contribute to Kryonux regardless of their abilities or the technologies they use.

## Accessibility Goals

We aim to:

- Use clear and readable documentation.
- Maintain consistent navigation across project resources.
- Provide meaningful descriptions for images where appropriate.
- Use sufficient color contrast in interfaces.
- Support keyboard navigation wherever possible.
- Avoid relying on color alone to communicate important information.
- Make error messages and instructions understandable.

## Known Limitations

Kryonux is an actively developed project. Not all components have undergone a formal accessibility audit.

Some interfaces, documentation pages, or features may have accessibility limitations. We welcome reports and contributions that help us identify and improve them.

## Reporting Accessibility Issues

If you encounter an accessibility barrier while using Kryonux, please report it through the project's GitHub Issues or community forum.

When reporting an issue, please include:

- A description of the accessibility problem.
- The affected page, feature, or component.
- Your browser, operating system, or assistive technology, if relevant.
- Steps to reproduce the issue, if possible.

Please avoid including private or sensitive personal information in public reports.

## Contributions

Contributions that improve accessibility are welcome. You can suggest improvements, report issues, or submit pull requests through the project's GitHub repository.

## Continuous Improvement

Accessibility is an ongoing process. We will continue working to identify limitations and improve the experience for everyone using Kryonux.
